# PDAN8412w – Part 1

## Project Overview
This repository contains Part 1 of the PDAN8412w Portfolio of Evidence.

The project focuses on the implementation and evaluation of a Recurrent Neural Network (RNN), specifically an LSTM model, for text-based data analysis and classification.

## Technologies Used
- Python
- PySpark
- TensorFlow/Keras
- Pandas
- Matplotlib
- Jupyter Notebook

## Contents
- Jupyter Notebook containing the implementation
- Data preprocessing and exploration
- LSTM model development and training
- Model evaluation and visualisations
